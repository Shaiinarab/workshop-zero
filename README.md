# کارگاه صفر — از کاربر به صاحبخانه

پیشنهاد یک برنامه آموزشی برای دانشجویان **موسسه آموزش عالی زند شیراز**: کارگاه صفر
(۱۸۰ دقیقه، سه ایستگاه) به‌علاوه یک **نقشه راه مدولار** که برای هر دانشجو از دلِ
پاسخ‌هایش ساخته می‌شود.

یک باینری. HTML روی سیم. بدون CDN، بدون کلید پرداختی، بدون وابستگی به شبکه.

```bash
go run ./cmd/server                 # http://localhost:8080
go run ./cmd/server freeze dist     # خروجی کاملاً ایستا
```

## ایده اصلی: یک نقشه راه، کاملاً مدولار

به جای سه مسیر جدا، یک ساختار واحد وجود دارد:

| بلوک | تعداد | چه کسی تغییرش می‌دهد |
|---|---|
| کارگاه صفر | ۱ | هیچ‌کس — برای همه یکسان |
| هسته مشترک | ۲ | هیچ‌کس — برای همه یکسان |
| **ماژول‌های انتخابی** | **۸** | **هر دانشجو (۴ ماژول)** |
| استودیوی پروژه | ۳ | هیچ‌کس — برای همه یکسان |
| Demo Day | ۱ | هیچ‌کس — برای همه یکسان |

جمعاً ۱۵ نشست. فقط هشت بلوک وسط با انتخاب هر کس عوض می‌شود؛ شروع و پایان یکی است.
این یعنی یک برنامه واحد برای کل موسسه، اما شخصی‌سازی‌شده برای هر دانشجو.

## هشت ماژول

هر ماژول دو نشست دارد: یکی برای فهمیدن، یکی برای ساختن.

| | ماژول | چه یاد می‌گیری |
|---|---|---|
| `m1` | هوش مصنوعی چطور کار می‌کند | توکن، زمینه، توهم، محدودیت دانش |
| `m2` | پرامپت و مهندسی زمینه | الگوهای پرامپت، زمینه‌سازی، خروجی ساختاریافته |
| `m3` | عامل‌های هوشمند | حلقه عامل، ابزار، خودگردانی، نظارت |
| `m4` | دانش خودت را به مدل بده | بازیابی و تولید، پایگاه دانش شخصی، استناد |
| `m5` | داده و تحلیل | کیفیت داده، تحلیل توصیفی، روایت داده |
| `m6` | تصویر، صدا و ویدیو | تولید تصویر، صدا، ویدیوی کوتاه، حق نشر |
| `m7` | از ایده تا نمونه | نمونه‌سازی سریع، بازخورد، تکرار |
| `m8` | اعتبار، اخلاق و ایمنی | راستی‌آزمایی، حریم خصوصی، صداقت علمی |

منبع: `internal/plan/modules.json` (در زمان بوت در باینری جاسازی می‌شود).

## مسیرها

| مسیر | صفحه |
|---|---|
| `/` | بوم پیشنهاد: ارزش، سه ایستگاه، ماژول‌ها، CTA |
| `/program` | برنامه ۱۸۰ دقیقه و سه ایستگاه |
| `/modules` | کتابخانه هشت ماژول |
| `/roadmap/{sel}` | نقشه راه ۱۵ نشستی (ساخت تدریجی روی SSE) |
| `/quiz/{id}` | آزمون مسیر (۱۰ سؤال) |
| `/result/{id}` | چهار ماژول پیشنهادی + QR + کارت اشتراک |
| `/tools` | ابزارها و پروژه‌های داغ |
| `/faq` | پرسش‌های متداول |
| `/live` | داشبورد مربی (با `LIVE_TOKEN` محافظت می‌شود) |

`{sel}` شکل/Modules انتخابی است: `m1,m3,m5,m7` یا `m1-m3-m5-m7` — هر دو کار می‌کنند
و همیشه به شکل نرمال (مرتب بر اساس شناسه) تبدیل می‌شود.

## معماری

- **Go + htmx 4 + TypeScript** — HTML روی سیم؛ سرور قطعه رندر می‌کند و مرورگر فقط
  htmx است. بدون SPA و بدون client-side router.
- **تقویت تدریجی** — هر فرم `action`/`method` واقعی دارد، پس آزمون با جاوااسکریپت خاموش
  هم کامل می‌شود.
- **دمو هرگز نمی‌میرد** — نقشه راه از کتابخانه ماژول ساخته می‌شود (نه از یک مدل زبانی)،
  پس هیچ کلید یا شبکه‌ای لازم نیست. `freeze` یک خروجی کاملاً ایستا می‌دهد که آفلاین کار
  می‌کند و آزمون را در مرورگر امتیازدهی می‌کند.
- **htmx 4.0.0** روی `4.0.0` پین شده (تگ `latest` هنوز ۲.x است). نکات مهم:
  - `hx-ext` حذف شده؛ افزونه‌ها با `<script>` اضافه می‌شوند و SSE با `hx-sse:connect`.
  - پاسخ چند-هدفه با `<template hx type="partial" hx-target="…">` — صفت `hx` بدون مقدار
    لازم است، وگرنه htmx آن را نادیده می‌گیرد.
- **TypeScript 7** با `tsc` معمولی، بدون bundler؛ دقیقاً سه ماژول: `theme`، `quiz-keys`،
  `quiz-static`.

## وضعیت و محدودیت‌ها

- **متن ۱۰ سؤال آزمون بازسازی‌شده است** — `PROMPT-v2 §4.4` در این مخزن موجود نبود.
  `internal/quiz/quiz-data.json` باید با متن اصلی جایگزین شود.
- داشبورد `/live` تقویم ۱۸۰ دقیقه را از ساعت ۹:۰۰ محاسبه می‌کند؛ برای اجرای واقعی
  باید ساعت شروع موسسه تنظیم شود.
- `LIVE_TOKEN` و `BASE_URL` و کلیدهای مدل اختیاری هستند؛ بدون آن‌ها برنامه کامل کار
  می‌کند.
