# کارگاه صفر — آزمایشگاه کاربردی هوش مصنوعی

پیشنهاد یک برنامه آموزشی پروژه‌محور برای دانشجویان مؤسسه آموزش عالی زند شیراز.

**مدل آموزشی:** هسته مشترک + سه مسیر تخصصی + پروژه نهایی

- **Creative AI Studio:** طراحی، تصویر، صدا، ویدیو و ارائه
- **AI Builder & Agent Engineering:** API، توسعه نرم‌افزار، گردش‌کار، Agent و RAG
- **AI Research & Intelligent Systems:** پژوهش، داده، ارزیابی، مدل محلی و امنیت

برنامه کامل و پیشنهاد اجرایی در [پروپوزال فارسی](content/proposal/proposal.md) و صفحه اصلی وب‌سایت قرار دارد.

## تصمیم آموزشی مهم

این مخزن یک کاتالوگ برنامه آموزشی را مستند می‌کند، نه وعده اجرای هم‌زمان تمام کارگاه‌ها. پیشنهاد اجرایی این است که ابتدا یک پایلوت ۸ ساعته برگزار شود:

1. هسته مشترک سواد AI و استفاده مسئولانه — ۲٫۵ ساعت
2. یک کارگاه تخصصی از مسیر منتخب — ۳ ساعت
3. استودیوی پروژه، بازخورد و ارائه — ۲٫۵ ساعت

پس از ارزیابی پایلوت، کارگاه‌های دیگر به‌تدریج اضافه می‌شوند. هیچ دانشجویی لازم نیست همه مسیرها را بگذراند.

## اصول اجرایی

- هر جلسه یک مهارت مشخص و یک خروجی قابل بررسی دارد.
- ابزارها قابل جایگزینی‌اند؛ هیچ سرویس تجاری، API پولی یا GPU اختصاصی پیش‌نیاز اجباری نیست.
- متن‌باز و قابل نصب اولویت دارند؛ سرویس‌های رایگان محدود با وضعیت دسترسی و جایگزین مشخص معرفی می‌شوند.
- فایل تمرین و مسیر آفلاین برای شرایط اینترنت ناپایدار آماده می‌شود.
- داده حساس دانشگاه یا دانشجو در سرویس عمومی بارگذاری نمی‌شود.
- ارزیابی بر اساس کیفیت خروجی، اعتبارسنجی، مستندسازی و ارائه انجام می‌شود.

## وب‌اپلیکیشن

این مخزن یک وب‌اپ سبک برای معرفی پیشنهاد، نمایش برنامه، منابع و نمونه ابزار شخصی‌سازی مسیر یادگیری دارد.

~~~bash
go run ./cmd/server
# http://localhost:8080

go run ./cmd/server freeze dist
~~~

ساختار فنی فعلی:
- Go برای سرور و رندر HTML
- htmx برای تعاملات تدریجی
- TypeScript برای تعاملات کوچک مرورگر
- محتوای Markdown و JSON جاسازی‌شده در باینری
- خروجی ایستا برای میزبانی و مشاهده آفلاین

**توجه:** آزمون و نقشه راه ۱۵ نشستی فعلی در وب‌اپ یک نمونه اولیه برای پیشنهاد مسیر خودآموزی است؛ این ابزار نباید با تقویم رسمی سه مسیر تخصصی اشتباه گرفته شود. محتوای آن در مرحله بعد با کاتالوگ جدید هم‌راستا خواهد شد.
