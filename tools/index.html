ابزارها

اکوسیستم ابزارها و ارائه‌دهندگان AI

راهنمای انتخاب برای کارگاه‌ها، نه فهرست وابسته به برند

ابتدا قابلیت و مسئله را مشخص می‌کنیم، سپس ابزار را انتخاب می‌کنیم. «متن‌باز»، «وزن‌باز»، «رایگان» و «دارای پلن رایگان» یک معنی ندارند:

  • Open source: کد با مجوز مشخص قابل بررسی، استفاده و تغییر است.
  • Open weights: وزن مدل قابل دریافت است؛ به‌تنهایی به معنی متن‌باز بودن داده، آموزش یا مجوز آزاد نیست.
  • Free to use: ممکن است رایگان اما اختصاصی و محدود باشد.
  • Freemium / free tier: استفاده رایگان با سقف، محدودیت مدل یا شرایط متغیر.
  • Trial credit: اعتبار آزمایشی یک‌باره، نه پلن رایگان پایدار.

۱. مدل‌ها و ارائه‌دهندگان API

این گزینه‌ها برای نمونه‌سازی، مقایسه مدل و اتصال API قابل بررسی‌اند. سهمیه‌ها و مدل‌های رایگان سریع تغییر می‌کنند؛ بنابراین این راهنما عمداً جدول ثابت سهمیه‌ها یا دسترسی کشورها ندارد. پیش از هر اجرا، مستندات رسمی و داشبورد حساب را بررسی کنید.

  • Google AI Studio / Gemini API: محیط آزمایش مدل‌های Gemini و API با tier رایگان برای مدل‌های منتخب. سقف‌ها به مدل و پروژه وابسته‌اند؛ داده‌های tier رایگان ممکن است برای بهبود محصولات Google استفاده شوند. داده محرمانه وارد نکنید.
  • GroqCloud: inference سریع برای مدل‌های open-weight با API سازگار با الگوهای رایج OpenAI. پلن رایگان مدل‌محور است؛ سقف واقعی در صفحه Limits حساب دیده می‌شود.
  • Cerebras Inference: گزینه‌ای برای تجربه inference سریع. اعتبار آزمایشی و دسترسی مدل‌ها را با free tier دائمی اشتباه نگیرید.
  • Cloudflare Workers AI: اجرای مدل‌های منتخب از طریق API و اکوسیستم Workers؛ سهمیه رایگان روزانه بر حسب Neurons تعریف شده و برخی مدل‌ها به پلن یا پرداخت نیاز دارند.
  • OpenRouter: درگاه واحد برای مقایسه و استفاده از مدل‌های متعدد. مدل‌های دارای شناسه :free سهمیه جداگانه دارند؛ provider پشت مدل، سیاست داده و ظرفیت آن اهمیت دارد.
  • SambaNova Cloud: API برای مدل‌های منتخب و مسیر آزمایش رایگان با محدودیت روزانه و مدل‌محور؛ headerهای نرخ محدودیت را بررسی کنید.
  • NVIDIA API Catalog: محیط آزمایش endpointهای مدل و نمونه‌های NIM؛ شرایط هر endpoint و مجوز استفاده تولیدی را جداگانه بخوانید.
  • Cohere: کلیدهای ارزیابی رایگان با محدودیت تعداد درخواست برای آزمایش RAG، embedding و reranking؛ کلید trial برای production یا استفاده تجاری طراحی نشده است.
  • Mistral AI: گزینه مهم برای مدل‌ها و ابزارهای توسعه؛ طبق مستندات فعلی، Free mode برای تجربه Vibe و Studio است و شامل API نمی‌شود؛ API نیازمند فعال‌سازی billing است.
  • Hugging Face: نقطه اصلی کشف مدل‌ها، دیتاست‌ها و providerهای گوناگون. دسترسی Inference Providers را رایگان فرض نکنید؛ اعتبار و شرایط به حساب و سرویس متصل وابسته است.
  • Ollama Cloud: گزینه ابری برای تجربه مدل‌ها؛ پلن و سهمیه آن را جدا بررسی کنید. با اجرای محلی Ollama یکی نیست.

هر راهنمای قدیمی درباره GitHub Models، endpointها یا سهمیه رایگان آن باید با وضعیت رسمی روز تطبیق داده شود. از snippetهای قدیمی به‌عنوان زیرساخت کلاس استفاده نکنید.

پروتکل بررسی provider پیش از هر نوبت

  1. صفحه رسمی pricing، rate limits و terms را باز کنید.
  2. مشخص کنید دسترسی رایگان دائمی است یا اعتبار آزمایشی.
  3. نام دقیق مدل و تاریخ بررسی را ثبت کنید.
  4. سقف RPM/TPM/RPD، محدودیت هم‌زمانی و نیاز به کارت یا احراز هویت را بررسی کنید.
  5. سیاست نگهداری داده، استفاده برای آموزش و محدودیت استفاده تجاری را بخوانید.
  6. یک درخواست آزمایشی بی‌خطر اجرا کنید و خطاهای 429، timeout و پاسخ ناقص را بررسی کنید.
  7. provider دوم یا مدل جایگزین آماده کنید.

انتخاب مدل به‌جای انتخاب برند

کیفیت استدلال، فارسی، کدنویسی، ورودی چندوجهی، context، latency، پایداری، هزینه، مجوز و سیاست داده را متناسب با مسئله بسنجید. تمرین پیشنهادی: سه مدل را با prompt و rubric یکسان آزمایش کنید و خروجی‌ها را با معیار مقایسه کنید، نه حس کلی «این یکی باهوش‌تر است».

۲. اجرای محلی و مدل‌های open-weight

  • Ollama: شروع ساده برای اجرای مدل محلی و ارائه API.
  • llama.cpp: اجرای مدل‌های GGUF با کنترل بیشتر روی CPU/GPU و quantization.
  • LM Studio: رابط دسکتاپ برای دریافت و آزمایش مدل‌های محلی؛ رایگان اما اختصاصی.
  • Jan: دستیار دسکتاپ local-first.
  • LocalAI: API سازگار برای اجرای محلی مدل‌های متنوع.
  • vLLM: serving با throughput بالا؛ مناسب مسیر سرور و پیشرفته.
  • SGLang: runtime و serving پیشرفته.
  • MLC LLM: کامپایل و اجرای مدل روی پلتفرم‌های مختلف.
  • Open WebUI: رابط self-host برای مدل‌های محلی و سرویس‌های سازگار.
  • llamafile: بسته‌بندی ساده‌تر مدل و runtime.

اجرای محلی به معنی رایگان بودن محاسبات، برق، حافظه یا فضای ذخیره‌سازی نیست. برای جلسه مقدماتی نمایش مدل کوچک یا از پیش آماده کافی است.

۳. آفرینش دیجیتال: تصویر، طراحی، ویدیو، صدا

تصویر و طراحی

  • ComfyUI: محیط node-based برای pipeline تصویر، ویدیو و صوت؛ مناسب نشان دادن فرایند تولید قابل مشاهده.
  • InvokeAI: canvas، inpainting و workflow برای تولید و اصلاح تصویر.
  • Krita + Krita AI Diffusion: پیوند نقاشی دیجیتال با pipelineهای تولید و ویرایش تصویر.
  • GIMP: ویرایش تصویر متن‌باز و محلی.
  • Penpot: طراحی رابط و prototype.
  • Inkscape: طراحی برداری.
  • Blender: مدل‌سازی سه‌بعدی، انیمیشن و رندر.
  • Photopea: ویرایشگر مرورگری برای PSD و تصویر؛ رایگان برای استفاده پایه اما متن‌باز نیست.

ویدیو و تصویر متحرک

  • Kdenlive و Shotcut: تدوین ویدیو.

صوت، گفتار و موسیقی

  • Audacity: ضبط و ویرایش صوت.
  • Whisper: تشخیص گفتار و تبدیل صوت به متن.
  • WhisperX: هم‌ترازی و timestamp برای transcription.
  • Piper: تبدیل متن به گفتار محلی و سبک.
  • Kokoro: مدل TTS با وزن‌های قابل دریافت؛ مجوز کد و وزن‌ها را جدا بررسی کنید.
  • Demucs: جداسازی stemهای صوتی.
  • RVC: تبدیل صدا؛ استفاده از صدای افراد واقعی نیازمند رضایت و رعایت حقوق آن‌هاست.
  • AudioCraft: ابزارهای پژوهشی تولید صوت و موسیقی؛ مجوز کد و وزن‌ها جداگانه بررسی شود.

تمرین Creative: یک داستان ۳۰ ثانیه‌ای را به storyboard، تصویر، صدای روایت و ویدیوی کوتاه تبدیل کنید. انسجام روایت و تصمیم هنری معیار اصلی است.

۹. تبدیل ابزار به تجربه آموزشی

هر ابزار فقط وقتی وارد برنامه می‌شود که نقش آموزشی روشن داشته باشد. برای هر ابزار ثبت کنید:

  • مسئله‌ای که حل می‌کند.
  • مفهوم فنی یا خلاقانه‌ای که آموزش می‌دهد.
  • خروجی قابل ساخت در ۳۰ تا ۹۰ دقیقه.
  • پیش‌نیاز دانشجو.
  • مجوز کد، وزن مدل، داده و دارایی تولیدی.
  • هزینه، سیاست داده و شرایط استفاده.
  • جایگزینی که مفهوم آموزشی را ثابت نگه می‌دارد.

در یک جلسه بیش از یک ابزار اصلی و یک ابزار مکمل معرفی نکنید، مگر اینکه خود مقایسه موضوع یادگیری باشد. به‌جای آموزش سطحی ۱۵ ابزار، یک خروجی واقعی را با یک ابزار بسازید و سپس جایگزین را نشان دهید.
