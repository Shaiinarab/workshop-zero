## راهنمای انتخاب ابزار

این فهرست، نقطه شروع است نه تضمین دسترسی یا رایگان‌بودن دائمی. شرایط هر سرویس، سهمیه، نیاز به حساب و دسترسی منطقه‌ای باید پیش از هر کارگاه دوباره بررسی شود.

### مدل‌های زبانی و دستیارها
- **ChatGPT / Claude / Gemini** — سرویس‌های اختصاصی با پلن‌ها و محدودیت‌های متغیر؛ فقط گزینه ابری، نه پیش‌نیاز قطعی.
- **Hugging Face Hub** — کشف مدل‌ها و دیتاست‌های open-weight؛ دسترسی API و اجرای مدل با محدودیت‌های جداگانه.
- **Ollama** — اجرای مدل‌های محلی و API روی سیستم شخصی؛ نیازمند دانلود اولیه مدل و حافظه کافی.
- **llama.cpp** — اجرای مدل‌های GGUF روی CPU و GPU؛ مناسب آزمایش محلی و سیستم‌های محدودتر.

### طراحی و تولید محتوای بصری
- **Photopea** — ویرایشگر مرورگری رایگان با تبلیغ؛ اختصاصی و وابسته به اینترنت.
- **GIMP / Krita** — ابزارهای متن‌باز برای ویرایش تصویر و نقاشی دیجیتال؛ قابل نصب و آفلاین.
- **Penpot** — طراحی رابط و نمونه‌سازی؛ متن‌باز و قابل میزبانی.
- **Excalidraw / diagrams.net** — دیاگرام، وایرفریم و ترسیم سریع؛ نسخه مرورگری و گزینه‌های محلی در دسترس‌اند.
- **ComfyUI** — گردش‌کار تولید تصویر با مدل‌های diffusion؛ متن‌باز، اما اجرای محلی مدل‌های سنگین به GPU و فضای ذخیره‌سازی نیاز دارد.

### صدا، موسیقی و ویدیو
- **Audacity** — ویرایش صوت متن‌باز و محلی.
- **Shotcut / Kdenlive** — تدوین ویدیو متن‌باز و محلی.
- **BandLab** — استودیوی آنلاین با پلن رایگان؛ نیازمند اینترنت و حساب.
- **Suno و سرویس‌های مشابه** — تولید موسیقی با سهمیه و شرایط استفاده متغیر؛ گزینه تکمیلی، نه زیرساخت اجباری.
- **Whisper** — تبدیل گفتار به متن؛ قابل اجرا به‌صورت محلی، با نیاز سخت‌افزاری متناسب با مدل.

### توسعه نرم‌افزار و API
- **Python یا JavaScript/TypeScript** — برای هر گروه فقط یک زبان اصلی انتخاب شود.
- **FastAPI یا Express** — چارچوب backend؛ انتخاب یکی متناسب با زبان گروه.
- **Git و GitHub** — نسخه‌بندی، مستندسازی و نگهداری خروجی پروژه.
- **Docker Compose** — اجرای تکرارپذیر سرویس‌ها؛ در سطح مقدماتی اختیاری است.
- **n8n** — اتوماسیون بصری و self-host؛ شرایط مجوز و محدودیت‌های نسخه باید بررسی شود.
- **LangGraph / LlamaIndex / LangChain** — چارچوب‌های توسعه پیشرفته؛ پس از فهم الگوی پایه معرفی شوند، نه در اولین تمرین.

### RAG، داده و ارزیابی
- **Qdrant یا Chroma** — پایگاه برداری؛ برای کارگاه مقدماتی یکی کافی است.
- **pandas / scikit-learn / Jupyter** — تحلیل داده و آزمایش‌های پایه.
- **Promptfoo** — تعریف تست و مقایسه خروجی مدل‌ها.
- **Zotero** — مدیریت منابع و ارجاع علمی.
- **Semantic Scholar / OpenAlex / Crossref** — کشف مقاله و فراداده علمی؛ کیفیت و پوشش منابع باید بررسی شود.

### انتخاب جایگزین
برای هر کارگاه باید در برگه اجرایی آن چهار مورد ثبت شود:
- ابزار اصلی و نسخه آن
- نوع دسترسی: متن‌باز، رایگان اختصاصی، freemium یا تجاری
- نیازمندی: اینترنت، حساب، سخت‌افزار و سیستم‌عامل
- جایگزین قابل اجرا و فایل تمرین آفلاین

**قاعده:** اگر تمرین بدون یک سرویس خاص قابل اجرا نیست، طراحی تمرین هنوز به‌اندازه کافی مقاوم نیست.
